# Yetmpay

Yetmpay is a Flutter application.

## Requirements

- [Flutter](https://docs.flutter.dev/get-started/install)
- A supported development environment for your target platform:
  - Android Studio for Android
  - Xcode for iOS and macOS
  - Chrome for web

Verify your Flutter installation with:

```bash
flutter doctor
```

## Getting Started

Clone the repository and install the project dependencies:

```bash
git clone https://github.com/kmax11/yetmpay.git
cd yetmpay
flutter pub get
```

Run the application on an available device or emulator:

```bash
flutter run
```

To list available devices:

```bash
flutter devices
```

## Development

Run the test suite:

```bash
flutter test
```

Analyze the project for code issues:

```bash
flutter analyze
```

Format Dart source files:

```bash
dart format .
```

## Building

Build for your target platform using the appropriate Flutter command. For example:

```bash
flutter build apk       # Android
flutter build ios       # iOS
flutter build web       # Web
```
